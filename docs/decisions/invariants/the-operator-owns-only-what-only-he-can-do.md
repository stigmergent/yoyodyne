## Must hold

An entry, finding, report, escalation, or request names the operator as its owner only for a reason on the closed list the ownership registry holds: a change of fundamental intent, or an act only a person can physically perform. The registry's resolver is the only code that names him, and every surface projects its answer.

## Why

A change whose own work is correct can still route something to the operator by deciding an owner locally, and each time it does, the autonomy goal fails without any check noticing. The operator's rule of 2026-09-26 treats every such routing as a defect. Enforced by the coverage test over the registry, the closed-reason test over every kind, and the test confining the operator's mover value to internal/ownership.
